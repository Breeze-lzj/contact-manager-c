# 手机通讯录管理系统（多数据结构实现）

> C 语言课程设计项目 · 用结构体数组 + 双链表索引实现的通讯录管理系统

## 项目简介

本项目是一个基于 C 语言的手机通讯录管理系统，通过**结构体数组主存储 + 双链表索引**的方式，实现了联系人信息的高效存储与多维度分组管理。支持按姓氏声母（27 组）智能分组、按群组（亲属/同事/同学/领导/朋友 5 类）分类，并提供完整的增删改查、排序、统计与数据持久化功能。

## 技术栈

- **语言**：C 语言（C99）
- **数据结构**：结构体数组、单链表、动态内存管理
- **存储**：二进制文件 IO（fread / fwrite）
- **交互**：多级文本菜单（字符界面）

## 功能模块

| 模块 | 功能说明 |
|------|----------|
| 联系人管理 | 添加、显示、查询、删除、修改联系人 |
| 声母分组 | 按中文姓氏拼音首字母自动分 27 组显示 |
| 群组分类 | 按亲属/同事/同学/领导/朋友 5 类分组管理 |
| 排序统计 | 按姓名/手机号排序，统计各分组人数 |
| 数据持久化 | 二进制文件保存与读取，重启数据不丢失 |
| 个人名片 | 编辑、查看、保存个人电子名片 |

## 核心设计亮点

1. **多索引架构**：数组主存储便于随机访问，同时建立 27 个声母链表索引 + 5 个群组链表索引，支持两种维度的快速遍历
2. **中文拼音首字母识别**：基于区位码查表实现汉字声母自动识别，支持中英文姓名
3. **动态扩容**：联系人数量超过初始容量时自动 realloc 扩容
4. **内存安全**：删除联系人时自动重建索引并释放链表节点内存，避免内存泄漏
